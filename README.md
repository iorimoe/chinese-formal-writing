# 中文写作国标指南

这项 Codex 技能根据文种和内容查阅相应的国家标准，辅助编写、修改和审查简体中文正式文稿。适用文种包括公文、学位论文、学术论文、科技报告、技术方案和操作说明。也可单独核对标题、摘要或一段正文。

## 安装

**通过 Git 安装。** 在 macOS 或 Linux 上执行以下命令。

```sh
git clone https://github.com/iorimoe/chinese-formal-writing.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/chinese-formal-writing"
```

**通过浏览器安装。** 在仓库首页选择 **Code → Download ZIP**。解压后，将包含 `SKILL.md` 的目录重命名为 `chinese-formal-writing`，连同其中的文件一起放入用户主目录下的 `.codex/skills/`。如已设置 `CODEX_HOME`，则放入该目录的 `skills/` 子目录。

## 使用示例

安装后，在 Codex 中输入 `$chinese-formal-writing`，并提供文稿或编写所需的资料。以下请求分别对应三种交付方式。

| 任务 | 示例请求 | 交付内容 |
| --- | --- | --- |
| 编写 | `$chinese-formal-writing` 根据附件中的试验记录编写科技报告摘要，保留测量条件和单位。 | 依据所给记录编写的摘要 |
| 修改 | `$chinese-formal-writing` 修改选中的操作说明，写清校验失败后的处理步骤，保留原有验收指标。 | 指定范围的修订稿 |
| 审查 | `$chinese-formal-writing` 审查这段论文摘要，逐项指出术语、数字和单位的问题。 | 问题位置、判断依据和修改建议，原稿保留 |

文种和读者决定适用的规则。例如，修改学位论文摘要时查阅学位论文条款，编写技术方案时沿用项目已有模板。日常写作按固定版本的条款摘要执行。安装包附有九项标准的 PDF，可从[国家标准索引](references/standards.md)按编号打开，离线查阅完整条文、图表和附录。文种与摘要的对应关系见[技能说明](SKILL.md)。

### 段落改写对照

以下原稿和修改稿均为自拟示例。

#### 阅览室临时关闭通知

**未使用技能**　11 月 20 日要检修设备，图书馆二楼阅览室从早上 9 点到中午 12 点先不开放。有读者需要还书的话，这段时间可以去一楼服务台办理。

**使用技能后**　因设备检修，图书馆二楼阅览室于 11 月 20 日 9 时至 12 时暂停开放。其间，读者可到一楼服务台还书。

#### 样件厚度检测报告

**未使用技能**　这次检测要求样件厚度在 1.95mm 到 2.05mm 之间。测下来甲是 1.96mm，乙是 2.04mm，都在这个范围里，丙是 2.06mm，比允许的最大值多了 0.01mm。

**使用技能后**　样件厚度的允许范围为 1.95 mm～2.05 mm。甲、乙样件的实测厚度分别为 1.96 mm 和 2.04 mm，均符合要求。丙样件的实测厚度为 2.06 mm，超过上限 0.01 mm。

#### 人员名单导入说明

**未使用技能**　导入人员名单时，文件里只要有一行没填工号，哪怕其他行都填了，也会整份导入失败，一条记录都不会写进去。系统会提示哪些行没填，按行号补好以后，还要把整个文件再导入一次。

**使用技能后**　导入人员名单时，若有记录缺少工号，系统会列出相应行号，不写入任何记录。请按行号补全工号，重新导入整份文件。
