# 中文写作国标指南

**依据九项国家标准编写、修改和审查简体中文正式文稿的 Codex 技能。**

- **公文、论文和科技报告**按文种查阅标准，核对文稿结构、参考文献和书写格式。
- **技术方案和操作说明**沿用原有模板，核对措辞、标点、数字和单位。
- **局部审查**可具体到一个标题、一段摘要或一张表。

## 段落改写对照

以下三组原稿和修改稿均为自拟示例。

### 样件厚度检测报告

> **未使用技能**
>
> 这次检测要求样件厚度在 1.95mm 到 2.05mm 之间。测下来甲是 1.96mm，乙是 2.04mm，都在这个范围里，丙是 2.06mm，比允许的最大值多了 0.01mm。

**使用技能后**

样件厚度的允许范围为 1.95 mm～2.05 mm。甲、乙样件的实测厚度分别为 1.96 mm 和 2.04 mm，均符合要求。丙样件的实测厚度为 2.06 mm，**超过上限 0.01 mm**。

> [!NOTE]
> 数值与单位符号之间的空格依据 GB 3100—1993 第 6.2.4 条。丙样件是否合格，按原稿给出的上限 2.05 mm 判断。[查看标准原文第 6 页](references/originals/GB-3100-1993.pdf#page=6)

### 阅览室临时关闭通知

> **未使用技能**
>
> 11 月 20 日要检修设备，图书馆二楼阅览室从早上 9 点到中午 12 点先不开放。有读者需要还书的话，这段时间可以去一楼服务台办理。

**使用技能后**

因设备检修，图书馆二楼阅览室于 11 月 20 日 **9 时至 12 时**暂停开放。其间，读者可到一楼服务台还书。

第一句交代关闭原因、地点和时段，第二句说明关闭期间在哪里还书。

### 人员名单导入说明

> **未使用技能**
>
> 导入人员名单时，文件里只要有一行没填工号，哪怕其他行都填了，也会整份导入失败，一条记录都不会写进去。系统会提示哪些行没填，按行号补好以后，还要把整个文件再导入一次。

**使用技能后**

导入人员名单时，若有记录缺少工号，系统会列出相应行号，**不写入任何记录**。请按行号补全工号，重新导入整份文件。

一行缺少工号会导致整份名单导入失败，因此要写清楚重新导入的范围。

## 安装

### 使用 Git 安装

在 macOS 或 Linux 上执行以下命令。条款摘要和原文 PDF 会随技能一起下载。

```sh
git clone https://github.com/iorimoe/chinese-formal-writing.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/chinese-formal-writing"
```

<details>
<summary>更新已通过 Git 安装的技能</summary>

```sh
git -C "${CODEX_HOME:-$HOME/.codex}/skills/chinese-formal-writing" pull --ff-only
```

</details>

### 下载 ZIP 安装

1. 在仓库首页选择 **Code → Download ZIP**，下载并解压。
2. 找到包含 `SKILL.md` 的目录，将其重命名为 `chinese-formal-writing`。
3. 将整个目录放入用户主目录下的 `.codex/skills/`，保留其中的 `agents/` 和 `references/`。若已设置 `CODEX_HOME`，则放入该目录下的 `skills/`。

## 使用示例

在 Codex 中输入 `$chinese-formal-writing`，附上原稿或写作所需的资料。

**可复制的检测报告修改请求**

```text
$chinese-formal-writing
请修改下面的检测报告。
保留样件名称、实测值和验收限值。
先给出修改稿，再列出单位写法的依据。
请注明标准编号和条款号。

[粘贴检测报告原文]
```

| 任务与交付内容 | 请求示例 |
| --- | --- |
| **编写** · 报告摘要 | 根据附件中的试验记录编写科技报告摘要，交代试验条件、方法和结果。 |
| **修改** · 段落修订稿 | 修改人员名单导入说明，写清哪些情况会导致导入失败，以及用户如何重新导入。 |
| **审查** · 问题清单 | 审查论文摘要中的术语、数字和单位。保留原稿，列出每处问题的位置、依据和修改建议。 |

## 标准与适用文种

点击标准编号可查阅条款摘要。摘要附有条款号和 PDF 页码，便于离线核对原文。[国家标准索引与原文](references/standards.md)

| 写作内容 | 核对事项 | 标准与条款摘要 |
| --- | --- | --- |
| 党政机关公文 | 标题、主送机关、正文、附件说明、成文日期 | [GB/T 9704—2012](references/official-documents.md) |
| 学位论文 | 论文构成、摘要、章节层级 | [GB/T 7713.1—2025](references/theses.md) |
| 学术论文 | 题名、摘要、正文、图表 | [GB/T 7713.2—2022](references/academic-papers.md) |
| 科技报告 | 报告构成、试验方法、结果和结论 | [GB/T 7713.3—2014](references/scientific-reports.md) |
| 引文和参考文献 | 文献类型、著录项目、正文引文 | [GB/T 7714—2025](references/bibliography.md) |
| 标点 | 句内停顿、句末点号、标号 | [GB/T 15834—2011](references/punctuation.md) |
| 数字 | 日期、数值范围、数字形式 | [GB/T 15835—2011](references/numbers.md) |
| 国际单位制 | 单位名称、单位符号及其书写 | [GB 3100—1993](references/si-units.md) |
| 量与符号 | 量值表达、量符号、单位换算 | [GB/T 3101—1993](references/quantities-symbols.md) |

查阅条款时，按原文区分“应”“宜”“可”。修改措辞时，保留原稿中的事实、操作步骤、适用条件和验收指标。[技能说明第 2 节](SKILL.md#2-语言与表达要求)
