# 中文写作国标指南

这项 Codex 技能用于编写、修改和审查简体中文正式文稿。编写公文、论文或科技报告时，按文种查阅国家标准。修改技术方案或操作说明时，沿用原有模板，核对措辞、标点、数字和单位。也可只审查一个标题、一段摘要或一张表。

[段落改写对照](#段落改写对照) · [安装](#安装) · [使用示例](#使用示例) · [标准与适用文种](#标准与适用文种)

## 段落改写对照

以下三组原稿和修改稿均为自拟示例。

### 样件厚度检测报告

**未使用技能**　这次检测要求样件厚度在 1.95mm 到 2.05mm 之间。测下来甲是 1.96mm，乙是 2.04mm，都在这个范围里，丙是 2.06mm，比允许的最大值多了 0.01mm。

**使用技能后**　样件厚度的允许范围为 1.95 mm～2.05 mm。甲、乙样件的实测厚度分别为 1.96 mm 和 2.04 mm，均符合要求。丙样件的实测厚度为 2.06 mm，超过上限 0.01 mm。

数值与单位符号之间的空格依据 GB 3100—1993 第 6.2.4 条。丙样件是否合格，则按原稿给出的上限 2.05 mm 判断。[查看单位书写条款原文，第 6 页](references/originals/GB-3100-1993.pdf#page=6)

### 阅览室临时关闭通知

**未使用技能**　11 月 20 日要检修设备，图书馆二楼阅览室从早上 9 点到中午 12 点先不开放。有读者需要还书的话，这段时间可以去一楼服务台办理。

**使用技能后**　因设备检修，图书馆二楼阅览室于 11 月 20 日 9 时至 12 时暂停开放。其间，读者可到一楼服务台还书。

第一句交代关闭原因、地点和时段，第二句说明关闭期间在哪里还书。

### 人员名单导入说明

**未使用技能**　导入人员名单时，文件里只要有一行没填工号，哪怕其他行都填了，也会整份导入失败，一条记录都不会写进去。系统会提示哪些行没填，按行号补好以后，还要把整个文件再导入一次。

**使用技能后**　导入人员名单时，若有记录缺少工号，系统会列出相应行号，不写入任何记录。请按行号补全工号，重新导入整份文件。

本例需要交代失败的范围。一行缺少工号会导致整份名单导入失败，因此操作说明须写清楚，补全工号后要重新导入整份文件。

## 安装

在 macOS 或 Linux 上使用 Git 安装整个技能目录，条款摘要和原文 PDF 会随技能一起下载。

```sh
git clone https://github.com/iorimoe/chinese-formal-writing.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/chinese-formal-writing"
```

通过上述命令安装后，可在需要更新时执行以下命令。

```sh
git -C "${CODEX_HOME:-$HOME/.codex}/skills/chinese-formal-writing" pull --ff-only
```

也可在仓库首页选择 **Code → Download ZIP**。解压后，将包含 `SKILL.md` 的目录重命名为 `chinese-formal-writing`，放入用户主目录下的 `.codex/skills/`。若已设置 `CODEX_HOME`，则放入该目录下的 `skills/`。保留 `agents/` 和 `references/` 子目录。

## 使用示例

安装后，在 Codex 中输入 `$chinese-formal-writing`，附上原稿或写作所需的资料。要修改前面的样件厚度报告，可复制这段请求，再粘贴原稿。

```text
$chinese-formal-writing 请修改下面的检测报告，保留样件名称、实测值和验收限值。先给出修改稿，再说明单位写法依据哪项标准、哪一条款。

[粘贴检测报告原文]
```

| 任务 | 可以这样提问 | 交付内容 |
| --- | --- | --- |
| 编写 | 根据附件中的试验记录编写科技报告摘要，交代试验条件、方法和结果。 | 根据记录起草的摘要。 |
| 修改 | 修改人员名单导入说明，写清哪些情况会导致导入失败，以及用户如何重新导入。 | 指定段落的修订稿。 |
| 审查 | 审查论文摘要中的术语、数字和单位。保留原稿，列出每处问题的位置、依据和修改建议。 | 可逐项核对的问题清单。 |

## 标准与适用文种

技能附有九项固定版本的国家标准。各条款摘要列出条款号和归档 PDF 页码，可离线核对正文、表格和附录。[国家标准索引与原文](references/standards.md)

| 写作内容 | 核对事项 | 标准与条款摘要 |
| --- | --- | --- |
| 党政机关公文 | 标题、主送机关、正文、附件说明和成文日期 | [GB/T 9704—2012](references/official-documents.md) |
| 学位论文、学术论文、科技报告 | 按文种核对文稿构成、摘要、标题层级和图表 | [学位论文 GB/T 7713.1—2025](references/theses.md)、[学术论文 GB/T 7713.2—2022](references/academic-papers.md)、[科技报告 GB/T 7713.3—2014](references/scientific-reports.md) |
| 引文和参考文献表 | 文献类型、著录项目及其与正文引文的对应关系 | [GB/T 7714—2025](references/bibliography.md) |
| 标点和数字 | 句内停顿、标号、日期、数值范围和数字形式 | [标点 GB/T 15834—2011](references/punctuation.md)、[数字 GB/T 15835—2011](references/numbers.md) |
| 量和单位 | 单位符号、数值与符号之间的空格、量值及其换算 | [国际单位制 GB 3100—1993](references/si-units.md)、[量与符号 GB/T 3101—1993](references/quantities-symbols.md) |

查阅标准时，按原文区分“应”“宜”“可”。修改措辞时，保留原稿中的事实、操作步骤、适用条件和验收指标。关于句式、术语和内容取舍的写作约定，见[技能说明第 2 节](SKILL.md#2-语言与表达要求)。
