# 参考文献著录条款摘要

## 1. 版本与来源

固定版本为 GB/T 7714—2025《信息与文献 参考文献著录规则》，核对日期为 2026 年 11 月 8 日。

- 标准信息：[全国标准信息公共服务平台](https://std.samr.gov.cn/gb/search/gbDetailedCNF?id=4507EFE13D37CB6AE06397BE0A0A601F)。
- 原文来源：[安徽商贸职业技术学院学报编辑部公开的标准 PDF](https://www2.abc.edu.cn/xbbjb/upload/2026-01/26012010262341.pdf)。
- 本文件整理第 4 章至第 9 章及规范性附录 A。附录 B 为资料性著录示例。

## 2. 信息与通用著录要求

| 条款号 | 本地使用要求 |
| --- | --- |
| 4.1—4.4 | 著录信息来自被引用资源本身，包括题名页、版权页、封面或电子资源的主要信息页。析出文献同时记录其自身信息与所属文献的信息。 |
| 5.1、5.2、5.6 | 文献按原有语种著录，数字一般保持原形；年份、卷期、页码、日期和序号等宜用阿拉伯数字。西文大小写按相应语种习惯处理。 |
| 6.1、6.2 | 顺序编码制的文献序号用方括号。各著录项目按规定使用前置符：句点分隔题名、版本、出版信息等，冒号引出副题名、出版者或页码，逗号分隔同类责任者及年份等，`//` 引出析出文献出处或会议名称。每条文献末尾可用句点。 |
| 7.1.1 | 个人责任者按姓前名后著录。西文姓氏完整书写且首字母大写，名字可缩写；汉语拼音姓名的姓氏完整书写且首字母大写，名字宜用全称。 |
| 7.1.2 | 同一著作方式的责任者不超过三人时全部列出；超过三人时可列前三人，后加“等”或相应外文词。 |
| 7.1.3、7.1.4 | 责任者不明时应标为“佚名”或相应外文词；顺序编码制可省略该项而从题名开始。机构责任者按资源记载著录，西文上下级机构用句点分隔。 |
| 7.2.1—7.2.3 | 题名及副题名取自信息源。无题名时，可依据资源内容拟题并加方括号；同一责任者的合订题名最多录前三项，参考文献不重复著录并列题名。 |
| 7.3、附录 A | 文献类型按类型代码标识；电子资源同时标注文献类型与载体代码，如 `[J/OL]`。 |
| 7.4 | 第一版可省略版次，其他版本说明应著录；古籍版本按原记载填写。 |
| 7.5.1—7.5.3 | 出版信息按出版地、出版者、日期排列，出版地用城市名。多个出版地或出版者宜选第一项或显要项。缺失时可标注“[出版地不详]”“[出版者不详]”；电子资源可省略对应缺失项。 |
| 7.5.4、7.6 | 出版年用公元纪年和阿拉伯数字。报告发布、专利公告、档案形成及电子资源创建、修改、引用日期等按 `YYYY-MM-DD` 著录。出版年缺失时，可依次采用版权年、印刷年或加方括号的估计年。 |
| 7.7、8.5.1.1 | 页码按实际来源著录；无页码而有文章编号时使用文章编号。期刊引文记录引用信息所在页，阅读型文献可记录全文起讫页或起始页。 |
| 7.8、7.9 | 访问地址按实际资源填写。地址已含永久标识符时可省略重复标识；地址未含时，可另列资源本身给出的 DOI、CSTR 等永久标识符。 |

## 3. 文献类型和格式

下表为依据相应条款整理的常用顺序编码制格式。尖括号中的文字为待填信息名称，实际著录时替换为资源信息。副题名、其他责任者、非首版版次等按第 7 章及各类型的著录项目补入。

| 条款号 | 文献类型 | 本地格式 |
| --- | --- | --- |
| 8.2.1、8.2.2 | 图书 | `<作者>. <题名>[M]. <版本>. <出版地>: <出版者>, <出版年>: <引文页码>.` |
| 8.3.1、8.3.2 | 图书中的析出文献 | `<析出作者>. <析出题名>[M]//<图书作者>. <图书题名>. <版本>. <出版地>: <出版者>, <出版年>: <析出页码>.` |
| 8.4.1、8.4.2 | 连续出版物整体 | `<责任者>. <刊名>[J]. <起始年>, <卷>(<期>)—<终止年>, <卷>(<期>). <出版地>: <出版者>, <出版年>.` |
| 8.5.1、8.5.2、8.5.3 | 期刊文章 | `<作者>. <题名>[J]. <刊名>, <年>, <卷>(<期>): <页码或文章编号>.` |
| 8.5.1.4、8.5.3 | 报纸文章 | `<作者>. <题名>[N]. <报纸名>, <出版日期>(<版次>).` |
| 8.6.1、8.6.3 | 会议文献 | `<责任者>. <题名>[C]//<会议名称>, <会议年份>: <引文页码>.` |
| 8.7.1、8.7.2 | 学位论文 | `<作者>. <题名>[D]. <学位授予单位所在地>: <学位授予单位>, <学位授予年>: <引文页码>.` |
| 8.8.1—8.8.3 | 报告 | `<责任者>. <题名>: <报告编号>[R]. <发布日期>: <引文页码>.` |
| 8.9.1、8.9.2 | 标准 | `<标准编号> <标准名称>[S].` |
| 8.10.1、8.10.2 | 专利 | `<申请者或所有者>. <题名>: <专利申请号>[P]. <公告或公开日期>: <引文页码>.` |
| 8.11.2、8.11.3 | 网站、网页 | `<责任者>. <题名>[EB/OL]. (<创建或修改日期>)[<引用日期>]. <访问地址>.` |
| 8.12.1—8.12.3 | 档案 | `<责任者>. <题名>: <档号>[A]. <收藏地>: <收藏者>, <形成日期>: <引文页码>.` |
| 8.13.1—8.13.3 | 地图 | `<责任者>. <题名>. <比例尺>[CM]. <版本>. <出版地>: <出版者>, <出版年>. <尺寸>.` |
| 8.14.1—8.14.3 | 联机数据集 | `<责任者>. <题名>[DS/OL]. <版本>. <发布平台>(<发布或修改日期>)[<引用日期>]. <访问地址>.` |
| 8.15.1、8.15.2 | 联机预印本 | `<责任者>. <题名>[PP/OL]. <版本>. <出版平台>(<创建或修改日期>)[<引用日期>]. <访问地址>.` |

第 8 章各表区分必备、有则必备和可选项目，日常处理如下。

- 题名和文献类型标识按各类型保留；标准文献必须有标准编号和标准名称。第 8.9.1 条允许标准化文件中的类型标识作为可选项。
- 报告编号、专利日期、引文页码等按信息源及相应著录项目填写。第一版版次、缺失的其他题名信息等不产生空占位内容。
- 联机资源按实际类型将标识写为 `[M/OL]`、`[J/OL]`、`[S/OL]` 等，并在条目后附访问地址；永久标识符按 7.9 处理。
- 网站、网页、数据集和预印本的引用日期为必备项目；该要求分别见表 10、表 11、表 14、表 15。
- 会议录、报告、数据集采用图书或期刊出版形式时，分别按 8.6.1、8.8.1、8.14.1 选择对应出版类型；档案和地图采用图书或图书析出文献形式时，分别按 8.12.1、8.13.1 处理。网页中的图书、论文等按 8.11.1 选择实际文献类型。
- 附录 A 的其他类型代码包括汇编 G、计算机程序 CP、数据库 DB、其他 Z。载体代码包括磁带 MT、磁盘 DK、光盘 CD、联机网络 OL、缩微资料 MM。

## 4. 正文引用与文献表

| 条款号 | 本地使用要求 |
| --- | --- |
| 9.1、9.2.1.1、9.2.2 | 顺序编码制按正文首次引用的先后次序连续编号，用方括号标注，文献表按编号排列。引文文献可集中列于文后，也可采用页下注释。 |
| 9.2.1.2 | 同一处多篇文献的序号用逗号分隔，连续编号可用短横线连接，如 `[2,4-6]`。计算机自动编码的脚注按原条款另行处理。 |
| 9.2.1.3 | 同一文献多次引用时复用首次编号，并在方括号外注明本次引文页码。计算机自动编号脚注可重复著录，后续条目可简化为此前序号及本次页码。 |
| 9.3.1.1、9.3.1.2 | 著者—出版年制在正文用圆括号标注作者和年份；正文已有作者时括号内只列年份。多作者文献标首位作者并加“等”或 `et al.`。 |
| 9.3.1.3、9.3.1.4 | 同一作者同年多篇文献，在年份后加 a、b、c 等区分；同一文献再次引用时按条款在括号外以角标注明引文页码。 |
| 8.1、9.3.2 | 著者—出版年制的文献表先按语种集中，再按作者字顺和年份排列，出版年移至作者之后；中文作者可按汉语拼音或笔画笔顺排序。 |

同一文稿的标引体系保持统一，正文引用与文献表逐项对应。上述格式中的符号按著录用途使用。
