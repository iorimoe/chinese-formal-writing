# 科技报告编写条款摘要

## 1. 版本与来源

固定版本为 GB/T 7713.3—2014《科技报告编写规则》，核对日期为 2026 年 11 月 8 日。

- 标准信息：[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=E2BA32B0F5E570E5844A9E7E2D42393F)。
- 原文来源：[清华大学图书馆公开的标准 PDF](https://lib.tsinghua.edu.cn/wj/GBT7713_3-2014.pdf)。
- 本文件对应第 4 章、第 5 章及规范性附录 A；附录 B 至附录 G 为资料性内容。

## 2. 组成与前置部分

| 条款号 | 本地使用要求 |
| --- | --- |
| 4.1 表 1 | 报告由前置、正文和结尾部分构成。封面、辑要页、目次、主体和结论为必备要素；参考文献、附录为有则必备；题名页、独立摘要页、建议、索引等按表 1 的可选属性处理。 |
| 4.2.1 c） | 题名表达报告主要内容，减少不常见缩写，避免字符和公式；可用副题名补充。分卷报告宜用副题名区别各卷内容并编号；题名、副题名宜中英文对照。 |
| 4.2.1 d）、e）、g）、h）、4.2.3 | 作者、单位、完成日期和资助项目按实际资料填写，机构使用规范名称；完成日期宜用 `YYYY-MM-DD`。封面、题名页和辑要页的重复信息应一致。 |
| 4.2.4、4.2.7 | 辑要页集中列出报告基本信息、摘要、关键词和总页数。报告应有中英文摘要；摘要和关键词置于辑要页，也可另设摘要页。 |
| 4.2.7 | 中文摘要一般为 300 字至 600 字，英文摘要一般约 300 个实词，特殊需要可增加。摘要应独立、客观地说明目的、方法、结果和结论，尽量减少图表、结构式及非公知符号、术语。 |
| 4.2.7 | 报告应选取 3 个至 8 个关键词，反映研究对象、领域、方法或结果，并在报告中有出处；关键词中英文对照，另行置于摘要下方。 |
| 4.2.8 | 报告应有目次，电子版目次应自动生成。目次一般列至第二级或第三级；已列层级中的全部章节应完整列出编号、标题和页码。 |
| 4.2.9、4.2.10 | 图表较多时列清单，写明编号、题名和页码；符号和缩略词等较多时汇集为说明表，置于图表清单之后。 |

## 3. 正文与结尾

| 条款号 | 本地使用要求 |
| --- | --- |
| 4.3.1、4.3.2 | 正文应客观、完整、层次清楚。引言简述背景、目的、对象、已有研究、理论基础和研究方法等。详细方法、结果及结论在相应正文部分展开。 |
| 4.3.3 | 主体完整描述理论、假设、方法、过程及关键装置、仪器和材料，提供专业读者重复研究过程、评价结果所需的信息；结果配必要图表、实验及观察数据，并讨论准确性和意义。 |
| 4.3.4、4.3.5 | 结论概括整体研究结果，客观说明发现及其影响。无法得出结论时进行必要讨论；后续行动建议依据实际结果和结论提出。 |
| 4.3.6 | 被引文献全部列入参考文献表，置于正文最后，宜另起页；未引用的补充阅读文献可置于附录“参考书目”。标引与著录采用[参考文献规则](bibliography.md)。 |
| 4.4.1 | 详细推导、计算程序、原始数据、设备资料等可置于附录；每个附录应在正文相应位置提及，宜另起页。 |

## 4. 编排

| 条款号 | 本地使用要求 |
| --- | --- |
| 5.1 | 中文报告采用规范简化汉字、标点及法定计量单位；印刷版宜用 A4，电子版采用通用文件格式。 |
| 5.2.2 | 章节一般不超过四级，均有编号和标题，编号与标题之间空一字。章号全文连续，节号在所属章、节内连续。 |
| 5.2.3 | 图、表、公式分别用阿拉伯数字依序编号，可全文连续编号；大中型报告可分章编号，章号与顺序号之间用短横线，如“图 2-1”。全文编号方式一致。 |
| 5.2.4 | 附录宜用大写拉丁字母依次编号。附录中的章节、图表、公式等在数字前加附录字母，如 `A1`、“图 A1”。附录编号和标题各占一行并居中。 |
| 5.2.5 | 前置部分用罗马数字独立编页，题名页为第 I 页；正文及结尾用阿拉伯数字连续编页。封面、封底不编页码，但计入总页数。 |
| 5.3.1 | 图应清晰且能独立说明信息，有编号，宜有图题；编号与图题置于图下，图注位于图题上方。图宜紧随首次引用处，并尽可能置于同页；跨页图标明续图及图题。 |
| 5.3.2 | 表应有编号，宜有表题，编号与表题置于表上，表注置于表下。表宜紧随首次引用处，建议用三线表；续表注明续表和表题，并重复表头。 |
| 5.3.3 | 需要相互引用的公式编号；编号加圆括号置于所在行或续行末行右端。长公式在运算符之前或括号之后换行。公式下方逐项解释符号和单位。 |
| 5.3.4 | 术语、符号和代号全文统一；非公知符号、缩略词等首次出现时说明。 |
| 5.4 | 文字说明可用脚注或尾注，长报告宜用脚注。图表及公式内的注释与正文注释分别编号，并置于对应图表或公式下方。 |
| 附录 E、附录 F | 字体字号及正文编排样式属于资料性示例。正文和章节标题的示例分别为五号宋体、五号黑体；具体排版结合当前报告模板确定。 |
