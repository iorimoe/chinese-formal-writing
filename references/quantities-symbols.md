## 2. 量、数值与量纲

| 条款号 | PDF 页码 | 本地使用要求 |
| --- | --- | --- |
| 2.1 | [1–2](originals/GBT-3101-1993.pdf#page=1) | 量值由数值与单位相乘构成。单位改变时，数值作对应换算，所表示的物理量保持相同。 |
| 2.1 的数值表示说明 | [2](originals/GBT-3101-1993.pdf#page=2) | 图表中的数值可用量与单位的比值表示，原文优先推荐这种形式；如表头写 `t/s`，表内填写时间以秒表示的数值。 |
| 2.2.1 | [2–3](originals/GBT-3101-1993.pdf#page=2) | 相加、相减的量属于可比较的同类量；乘除按量及单位的代数关系处理。指数、对数和三角函数的自变量为数或量纲为一的组合。 |
| 2.2.2 | [3](originals/GBT-3101-1993.pdf#page=3) | 通常优先采用与单位选择无关的量方程。采用依赖特定单位的数值方程时，正文必须注明各量采用的单位。 |
| 2.2.6 | [4](originals/GBT-3101-1993.pdf#page=4) | 量纲由基本量量纲的幂积表示。基本量纲符号为 L、M、T、I、Θ、N、J；量纲指数均为零时，量纲为 1。量纲与单位分别表达。 |
| 2.3.3 | [8](originals/GBT-3101-1993.pdf#page=8) | 量纲为一的量可直接用数表示，单位 1 通常省略，倍数和分数用 10 的幂表示；百分号表示因数 0.01，具体份额名称写在量名称中。 |

依据 2.2.6（[PDF 第 4 页](originals/GBT-3101-1993.pdf#page=4)）编制的本地示例：速度的量纲为 LT⁻¹，SI 单位为 m/s；力的量纲为 LMT⁻²，SI 单位为 N。

## 3. 符号与量值排版

| 条款号 | PDF 页码 | 本地使用要求 |
| --- | --- | --- |
| 3.1.1 | [9–10](originals/GBT-3101-1993.pdf#page=9) | 量符号通常使用单个拉丁字母或希腊字母，可带下标；量符号采用斜体。 |
| 3.1.2 | [10](originals/GBT-3101-1993.pdf#page=10) | 表示物理量或变量的下标采用斜体；表示说明文字、固定编号的下标采用正体。 |
| 3.1.3 | [10–11](originals/GBT-3101-1993.pdf#page=10) | 量符号的乘除按数学关系表示；同一行使用斜线时，通过括号明确分母范围，避免连续斜线造成歧义。 |
| 3.2.1 | [11](originals/GBT-3101-1993.pdf#page=11) | 单位符号使用正体，放在完整数值之后并留空隙。测量条件、最大值等说明放在量符号或正文中。 |
| 3.2.2、3.2.3 | [11](originals/GBT-3101-1993.pdf#page=11) | 组合单位用乘点、空隙、斜线或负指数表达；词头用正体，与单位连写，并与单位共同接受幂运算。 |
| 3.3.1 | [12](originals/GBT-3101-1993.pdf#page=12) | 数字一般用正体。科学技术文稿的多位数从小数点向两侧每三位分组，组间用空隙；分组符号不采用逗号或圆点。 |
| 3.3.2、3.3.3 | [12](originals/GBT-3101-1993.pdf#page=12) | 中文文稿的小数记号用基线圆点；绝对值小于 1 的小数保留点前零。数字相乘采用“×”。 |
| 3.4 | [12](originals/GBT-3101-1993.pdf#page=12) | 数值与单位之间留空隙，摄氏温度同样如此；平面角的度、分、秒符号紧接数值，如 `30°`。 |
| 3.4 | [12](originals/GBT-3101-1993.pdf#page=12) | 量值的和、差及偏差可以整体加括号后带共同单位，或各量分别带单位，如 `（20.0 ± 0.2）mm`、`5 m + 3 m`。 |
| 3.5 | [12–13](originals/GBT-3101-1993.pdf#page=12) | 化学元素符号用正体；质量数置于左上标，原子序数可置于左下标，分子中原子数置于右下标，离子态或激发态可置于右上标。 |

数据的有效数字、测量条件及计算精度取自原始资料。单位名称和词头的共同规则见[国际单位制条款摘要](si-units.md)。
