# 国际单位制及单位书写条款摘要

## 1. 版本与来源

固定版本为 GB 3100—1993《国际单位制及其应用》，核对日期为 2026 年 11 月 8 日。

- 标准信息：[全国标准信息公共服务平台](https://std.samr.gov.cn/gb/search/gbDetailedCNF?id=71F772D7AA78D3A7E05397BE0A0AB82A)。
- 原文来源：[广东轻工职业技术大学科学技术部发布页](https://kyc.gdipu.edu.cn/info/1020/1152.htm)及其[标准 PDF](https://kyc.gdipu.edu.cn/__local/1/2D/E2/94E88C83422878ED4C59D0B21D0_818C517F_E74A0.pdf?e=.pdf)。
- 本地原文：[标准全文（PDF）](originals/GB-3100-1993.pdf)。
- 本文件整理第 3 章至第 7 章中单位名称、符号及书写要求。

## 2. 基本单位与常用导出单位

第 3.1 条表 1 规定的基本单位如下。

| 量 | 单位名称 | 符号 |
| --- | --- | --- |
| 长度 | 米 | m |
| 质量 | 千克 | kg |
| 时间 | 秒 | s |
| 电流 | 安培 | A |
| 热力学温度 | 开尔文 | K |
| 物质的量 | 摩尔 | mol |
| 发光强度 | 坎德拉 | cd |

第 3.2 条表 2 中，与一般技术写作有关的导出单位包括：频率用 Hz，力用 N，压力用 Pa，能量用 J，功率用 W，电荷量用 C，电压用 V，电阻用 Ω，摄氏温度用 °C。组合单位按量的关系构成，如速度用 m/s、加速度用 m/s²。

## 3. 词头、名称与符号

| 条款号 | 本地使用要求 |
| --- | --- |
| 3.3、表 4 | SI 词头表示十进倍数或分数，与单位结合使用。常用词头为 T（10¹²）、G（10⁹）、M（10⁶）、k（10³）、h（10²）、da（10¹）、d（10⁻¹）、c（10⁻²）、m（10⁻³）、μ（10⁻⁶）、n（10⁻⁹）、p（10⁻¹²）。 |
| 3.3 | 词头不单独使用、不重叠；词头和紧随的单位共同接受幂运算，如 `cm² = 10⁻⁴ m²`。质量的倍数和分数单位由词头与 g 构成，如 mg。 |
| 4.1、4.2 | 单位选择便于读写；倍数单位一般使数值处于 0.1 至 1 000 之间。同一量的表格或对照性叙述使用同一单位时，数值可超出这一范围。 |
| 4.3、4.4 | 组合单位一般只用一个词头，优先置于首个单位或分子首个单位；计算时建议将词头换成 10 的幂。原条款对 kg 及部分长度、面积、体积组合保留专门用法。 |
| 5.2—5.5 | 组合单位名称按符号顺序表达，除法用“每”，整个名称只出现一次“每”；名称中不夹乘除符号。面积和体积分别用“平方米”“立方米”等名称。 |
| 6.1.3、6.1.5 | 单位符号无复数变化，符号上不增加说明性标记；组合单位使用同一符号系统，如 km/h。 |
| 6.2.1 | 单位符号用正体。一般用小写，源于人名的单位首字母大写，L 为原条款列明的例外。大小写直接影响含义。 |
| 6.2.2 | 相乘单位可用居中点或空隙，如 `N·m`；相除单位可用斜线或负指数。多个分母单位用括号明确关系，如 `J/(kg·K)`。 |
| 6.2.4、6.2.5 | 单位符号写在完整数值之后，数值与单位之间留空隙；词头与单位符号连写。 |
| 6.2.6 | 单位名称和符号作为整体使用。摄氏温度写为 `20 °C`，符号 °C 保持完整。 |
| 7.1、表 5、7.2 | 标准还规定可与 SI 并用的法定单位，包括 min、h、d、L、t 等，并允许按实际需要构成 km/h 等组合。换算关系为 `1 min = 60 s`、`1 h = 3 600 s`、`1 L = 10⁻³ m³`、`1 t = 10³ kg`。 |

## 4. 技能采用方式

用户要求物理量采用国际单位制，新写量值据此选用 SI 单位。已有事实和参数的单位换算保留数值等价关系；日期、页数、人数及软件标识按其实际含义书写。量纲、量符号、角度间隔和带偏差的量值见[量与符号规则](quantities-symbols.md)。
