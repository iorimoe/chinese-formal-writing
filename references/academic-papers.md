# 学术论文编写条款摘要

## 1. 版本与来源

固定版本为 GB/T 7713.2—2022《学术论文编写规则》，核对日期为 2026 年 11 月 8 日。

- 标准信息：[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=0B963916637B8F34B295FCF4A51A1BE5)。
- 原文来源：[《南方水产科学》网站公开的标准 PDF](https://www.schinafish.cn/fileNFSCKX/cms/news/info/2023/02/38e800ebd58046bebe93af5a41139af1/GBT%207713.2%E2%80%942022.pdf)。
- 本文件对应第 4 章、第 5 章和规范性附录 A。附录 B 的字体字号表属于资料性参考。

## 2. 题名、摘要与正文

| 条款号 | 本地使用要求 |
| --- | --- |
| 4.1、附录 A 表 A.1 | 论文包括前置、正文和附录部分。题名、作者信息、摘要、关键词、引言、主体和参考文献为必备要素；结论、附录按有则必备处理，致谢为可选要素。 |
| 4.2.1 | 题名应准确表达主要内容，使用标准术语、学名全称或通用名称，避免宽泛、夸大的词语；一般不宜超过 25 字。必要时可用副题名补充，题名在各处应一致；宜有外文题名。 |
| 4.2.2 | 作者信息包括姓名、工作单位和通信方式，按实际贡献署名。集体成果列出作者姓名，按贡献大小排序；中国作者姓名的汉语拼音采用姓前名后、双名连写且名字不缩写的形式。 |
| 4.2.3 | 摘要应独立表达论文信息，通常说明目的、方法、结果和结论。一般以报道性摘要约 400 字、报道／指示性摘要约 300 字、指示性摘要约 150 字为宜，字数与成果内容相适应。 |
| 4.2.3 | 摘要可含公式、图表等，但不含其编号及参考文献编号。非公知简称、外文缩略语首次出现时应说明。中外文摘要内容宜对应，外文摘要可包含更多信息。 |
| 4.2.4 | 关键词应反映论文主题并具有检索意义，宜为 3 个至 8 个，置于摘要之后；宜选用主题词表、专业词表中的词语，重要的新术语及特定名称也可采用。 |
| 4.2.5 a） | 基金资助项目形成的论文应标注基金名称和项目编号。 |
| 4.3.1、4.3.2 | 正文表达应真实、完整、准确且逻辑清晰。引言通常说明背景、目的、研究理由及预期结果的意义，客观介绍前人工作与本研究。 |
| 4.3.3 | 主体应说明理论、方法、假设、技术、步骤、参数及关键设备、材料或研究对象，使专业读者能够依据这些信息重复研究过程；结果配必要数据、图表和讨论。 |
| 4.3.4 | 结论概括整体研究结果和论点，编章编号；无法形成结论时可采用结束语，陈述讨论、建议及待解决问题。 |
| 4.3.5、4.3.6 | 致谢客观记录实际贡献，可置于结论之后，一般不编章号。参考文献应与主题直接相关，按[参考文献规则](bibliography.md)统一标引和著录。 |
| 4.4 | 影响正文结构但有必要保留的原始数据、推导、程序、设备或技术细节，可置于论文末尾的附录。 |

## 3. 编号、图表与公式

| 条款号 | 本地使用要求 |
| --- | --- |
| 5.1 | 中文正文采用规范汉字和符合汉语语法的表达，做到题文一致、用词准确、结构严谨。印刷版宜用 A4；电子版采用通用格式。 |
| 5.2.2 | 章节一般不宜超过四级，标题一般不宜超过 15 字。章应有标题；节宜有标题，同一层次保持一致。 |
| 5.2.2 | 章节宜使用 `1`、`1.1`、`1.1.1` 等编号，末位数字后无点号；编号顶格，其后空一字接标题，标题末尾无标点，正文另起行。有“引言”标题时可编为 `0`。传统编号方法也可采用。 |
| 5.2.3—5.2.5 | 列项可用阿拉伯数字、小写拉丁字母或符号，编号与公式序号应区分。图、表、公式分别用阿拉伯数字依序编号；只有一个图或表时仍编为“图 1”“表 1”。附录依次用大写拉丁字母编号。 |
| 5.4.1—5.4.5 | 插图应清晰、能独立表达信息，有编号和图题，编号与图题居中置于图下，宜紧随首次提及该图的文字。坐标标目采用量名称或符号与单位之比的形式，如 `t/s`。 |
| 5.5.1—5.5.5 | 表应有编号、表题和表头，编号与表题置于表上，表注置于表下；表头不使用斜线分栏。相同内容重复写出或合并单元格。续表注明续表标识并重复表头。 |
| 5.5.4 | 表内空白表示无此项或未测量，“—”表示测量过而未发现，“0”表示实测结果为零；原始数据的状态按其实际含义记录。 |
| 5.6.3、5.6.4 b） | 连续数据的分组范围应明确端点是否包含，避免区间交叠；有效数字应完整保留。 |
| 5.7.2—5.7.4 | 优先使用量关系式，符号含义随公式解释；数值关系式注明所用单位。被引用的编号公式及大公式另行居中，编号在最右端。换行首选在关系符号或运算符号后断开，下一行不重复符号；原条款也允许在符号前断开。 |
| 5.8 | 注释宜采用正文编号与页下注释对应的形式，编号与参考文献脚注区分。 |

## 4. 术语、量和单位

| 条款号 | 本地使用要求 |
| --- | --- |
| 5.3.2、5.3.3、5.9 | 量名称和符号使用规范形式，科学技术名词优先采用全国科学技术名词审定委员会公布的名称；同一概念的名称在全文一致。未经审定的字母词首次出现时应括注中文译名，必要时注明外文全称。 |
| 5.3.5、5.3.6 | 量值使用正体单位国际符号，数字与符号间留空隙；单位符号上不附加测量条件等说明。单位英文缩写及 `ppm` 等数量份额缩写不作为单位符号，后者宜用 10 的幂表达。 |
| 5.3.7、5.3.8 | 词头与单位符号连写，词头不独用、不重叠；二进制倍数词头按 `Ki`、`Mi`、`Gi`、`Ti`、`Pi`、`Ei`、`Zi`、`Yi` 书写，分别对应 2 的 10、20、30、40、50、60、70、80 次幂。 |
| 5.3.9 | 相乘的各量值分别带单位，如 `20 mm × 30 mm`。同单位范围的前一单位宜省略；百分数范围保留两端百分号。 |

共同书写内容见[标点](punctuation.md)、[数字](numbers.md)、[国际单位制](si-units.md)和[量与符号](quantities-symbols.md)。
