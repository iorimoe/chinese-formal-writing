# 学位论文编写条款摘要

## 1. 版本与来源

固定版本为 GB/T 7713.1—2025《信息与文献 编写规则 第1部分：学位论文》，核对日期为 2026 年 11 月 8 日。

- 标准信息：[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=36C05B5738C54D42B4B262525320B52F)。
- 原文来源：[湖南农业大学研究生院公开的标准 PDF](https://yjsy.hunau.edu.cn/xwgz/xgxz_1462/202603/P020260325595645822472.pdf)。
- 本地原文：[标准全文（PDF）](originals/GBT-7713.1-2025.pdf)。
- 本文件对应第 4 章至第 6 章和规范性附录 A。附录 B 至附录 H 为资料性编排示例。

## 2. 文字、题名与前置内容

| 条款号 | 本地使用要求 |
| --- | --- |
| 4.1、4.2 | 内容应完整、准确；中文稿采用规范汉字和规范标点。外语教学采用外语撰写时，应同时提供中文题名和中文摘要。 |
| 4.3 | 术语、符号和代号在全文一致。专业术语和缩略词首次出现时应注释；外文术语、缩略词的译文后用圆括号注明原文全称。 |
| 4.4—4.6 | 数字、量和单位采用相应标准规则。印刷论文宜用 A4；电子论文应使用通用文件格式，可附音频、视频和数据集。 |
| 5.1、附录 A 表 A.1 | 论文按前置部分、正文、参考文献、附录、索引和结尾部分组织。题名页、原创性声明、使用授权说明、摘要页、目次页、正文和参考文献为必备内容。封面、英文题名页、索引、作者简历等按表 A.1 的可选属性处理。 |
| 5.2.3 f） | 题名一般不宜超过 25 字，通常采用名词性短语，准确反映主要研究内容，并应中英文对照。题名宜减少不常用缩写、符号、代号和公式；可用副题名限定或补充内容。论文各处题名应一致。 |
| 5.2.3 e）、g）—l） | 题名页按实际信息填写学位授予单位、学生姓名和学号、导师及专业技术职务、学位、学科专业、研究方向、提交日期和培养单位。机构采用规范全称；校外导师一并列出。 |
| 5.2.6、5.2.7 | 论文应有原创性声明和使用授权说明；引用或参考内容应注明来源。声明信息依据作者实际情况及学位授予单位要求填写。 |
| 5.2.9 | 摘要应能独立传达主要信息，宜说明目的、方法、结果和结论，重点在结果和结论。中文撰写的论文，中文摘要一般为 300 字至 1 000 字，特殊需要时可增加。摘要宜减少图表、化学结构式和非公知符号、术语。 |
| 5.2.9 | 每篇论文应选取 3 个至 8 个关键词，另行置于摘要下方；关键词采用体现论文内容的专业词语，并在论文中有明确出处。 |
| 5.2.9 | 中文论文宜附英文摘要，另页置于中文摘要之后，内容宜对应，并配对应关键词。外文论文应有同语种摘要及中文摘要；中文摘要置于外文摘要之后，宜不少于 5 000 字。 |
| 5.2.10—5.2.13 | 序言或前言可说明背景、目的及编写情况。目次另页编排；图表较多时分别列出图、表清单，写明编号、题名和页码。需集中解释的符号和缩略词等置于图表清单之后。 |

## 3. 正文与引用

| 条款号 | 本地使用要求 |
| --- | --- |
| 5.3.1 | 正文通常由引言、主体和结论构成。引言说明已有研究、研究目的、流程和方法；主体按研究内容组织，论证和表达应准确、完整、合乎逻辑。正文从另页右页开始，每章另起页。 |
| 5.3.2 | 图应能独立说明所表达的信息并随文出现，使用阿拉伯数字编号，图多时可分章编号。图题宜设置，编号和图题置于图下。照片应清晰，需有表示对象尺寸的标度。 |
| 5.3.3 | 表应随文出现并独立表达信息，使用阿拉伯数字编号，表多时可分章编号。表题宜设置，编号和表题置于表上。宜采用三线表；续表重复编号和表头，编号后标“（续）”。 |
| 5.3.4 | 公式另行编排。公式有两个以上时使用阿拉伯数字编号，编号加圆括号并右端对齐；公式较多时可分章编号。长公式宜在关系符号或运算符号后换行。 |
| 5.3.5、5.4 | 引文和文献表按[参考文献规则](bibliography.md)编排，全文统一标引体系。全部被引文献列入参考文献表，文献表置于正文之后并另起页。未引用而具有补充价值的阅读文献可置于附录“参考书目”。 |
| 5.3.6 | 对词语的补充解释可采用注释，宜采用文中编号与页下注释对应的形式，并控制数量。 |
| 5.3.7 | 结论提炼论文整体成果，说明核心观点、实际研究局限及后续建议。无法导出确定结论时，条款允许以必要讨论处理。 |
| 5.5、5.6 | 详尽方法、原始数据、数学推导及数字资料等可作为附录；索引可按主题、概念和术语编制，置于附录之后。 |

## 4. 编排

| 条款号 | 本地使用要求 |
| --- | --- |
| 6.5.1、6.5.2 | 章、节按内容划分。编号顶格，编号与标题之间空一字；章标题占二行。正文另起行，首行空二字，回行顶格。 |
| 6.6 | 前置部分使用罗马数字独立连续编页，封面除外；正文及后置部分使用阿拉伯数字连续编页。 |
| 6.8 | 附录编号和标题各占一行并居中；每个附录通常另起页，多个短附录可接排。 |
| 6.10 | 印刷版上边、左边留白分别不少于 25 mm，下边、右边分别不少于 20 mm。 |

学位授予单位的具体模板信息由当前文档资料提供；本地条款保留上述固定版本的要求。
