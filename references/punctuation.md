# 标点符号用法条款摘要

## 1. 版本与来源

固定版本为 GB/T 15834—2011《标点符号用法》，核对日期为 2026 年 11 月 8 日。

- 标准信息：[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=22EA6D162E4110E752259661E1A0D0A8)。
- 原文来源：[金陵科技学院学报编辑部公开的标准 PDF](https://xbbjb.jit.edu.cn/GBT15834-2011.pdf)。
- 本地原文：[标准全文（PDF）](originals/GBT-15834-2011.pdf)。
- 本文件整理第 4 章（[PDF 第 5–16 页](originals/GBT-15834-2011.pdf#page=5)）、第 5 章（[PDF 第 16–17 页](originals/GBT-15834-2011.pdf#page=16)）及规范性附录 A（[PDF 第 18–21 页](originals/GBT-15834-2011.pdf#page=18)）中与正式文稿相关的用法。附录 B（[PDF 第 22–25 页](originals/GBT-15834-2011.pdf#page=22)）为资料性说明，其中 B.3.2 至 B.3.8 的序次语用法和 B.4 的文章标题用法见[PDF 第 25 页](originals/GBT-15834-2011.pdf#page=25)。

PDF 页码按归档文件的页序计算，首页为第 1 页。页码范围链接至起始页。

## 2. 句内与句末标点

| 条款号 | PDF 页码 | 本地使用要求 |
| --- | --- | --- |
| 4.1.3.1 | [5](originals/GBT-15834-2011.pdf#page=5) | 语意完整、具有陈述语气且存在较大停顿的句末使用句号。句子长短不决定句号的使用。 |
| 4.4.3.1、4.4.3.2 | [7](originals/GBT-15834-2011.pdf#page=7) | 复句分句之间通常用逗号；较长主语、前置谓语、较长宾语及句首状语之后，可按实际停顿使用逗号。 |
| 4.5.3.1、4.5.3.3 | [8](originals/GBT-15834-2011.pdf#page=8) | 并列词语之间用顿号；不带括号的汉字数字序次语后用顿号，如“一、”。 |
| 4.5.3.4 | [8](originals/GBT-15834-2011.pdf#page=8) | 相邻数字表示概数时通常连写，如“三四项”；表示彼此独立的确定数或缩略列举时，按实际并列关系使用顿号。 |
| 4.5.3.5 | [8](originals/GBT-15834-2011.pdf#page=8) | 相邻的引号项、书名号项之间通常省略顿号；各项之间有其他插入成分时可用顿号。 |
| 4.6.3.1—4.6.3.3、A.5 | [8–9](originals/GBT-15834-2011.pdf#page=8)、[18–19](originals/GBT-15834-2011.pdf#page=18) | 分号用于复句中较高层次的分句停顿及分项列举。列举项中已有句号时，各项末尾采用句号。 |
| 4.7.3.1—4.7.3.3、A.6.1—A.6.3 | [9](originals/GBT-15834-2011.pdf#page=9)、[19](originals/GBT-15834-2011.pdf#page=19) | 冒号用于提示下文、总结上文或引出解释，所提示的范围与前面的说明相对应；无提示性停顿时按句法使用其他标点。 |
| 4.7.3.5 | [9](originals/GBT-15834-2011.pdf#page=9) | 同一句一般避免重复嵌套冒号；条文列举确有需要时，后续层次宜另起段落。 |
| A.1 | [18](originals/GBT-15834-2011.pdf#page=18) | 图表的短语式说明文字末尾不用句号。 |
| A.2 | [18](originals/GBT-15834-2011.pdf#page=18) | 含疑问词的陈述句仍按陈述语气使用句末标点。 |

## 3. 标号

| 条款号 | PDF 页码 | 本地使用要求 |
| --- | --- | --- |
| 4.8.3.1、4.8.3.4 | [9–10](originals/GBT-15834-2011.pdf#page=9) | 直接引文用引号；外层用双引号“”，内层用单引号‘’。 |
| 4.8.3.5 | [10](originals/GBT-15834-2011.pdf#page=10) | 独立成段的多段引文，各段开头用前引号，仅在最后一段末尾用后引号。 |
| 4.9.3.1、4.9.3.4、A.8 | [10–11](originals/GBT-15834-2011.pdf#page=10)、[19](originals/GBT-15834-2011.pdf#page=19) | 圆括号用于解释、补充等。句内括注紧随被解释词语，句外括注放在被解释语段的句末标点之后；公文发文年份采用六角括号“〔〕”。 |
| 4.9.3.6 | [11](originals/GBT-15834-2011.pdf#page=11) | 一般文字中的括号宜减少嵌套；确需嵌套时按条款区分括号形式。数学与逻辑公式采用其专业符号规则。 |
| 4.10.2、4.10.3.1、4.10.3.9 | [11–12](originals/GBT-15834-2011.pdf#page=11) | 破折号写作“——”，可引出补充说明或副标题；正式文稿的补充信息同时遵循用户规定的直接陈述方式。 |
| 4.11.2、4.11.3.1、A.9.2 | [12](originals/GBT-15834-2011.pdf#page=12)、[19](originals/GBT-15834-2011.pdf#page=19) | 省略号写作“……”，可表示引文删节；省略号与“等”“等等”不重复并用。 |
| 4.13.2、4.13.3.1、4.13.3.2、A.11 | [13–14](originals/GBT-15834-2011.pdf#page=13)、[20](originals/GBT-15834-2011.pdf#page=20) | 短横线用于编号连接、日期简写等；一字线用于时间、地域的起止，数值范围可用浪纹线。各符号按其含义选用。 |
| 4.14.3.4、A.12 | [14](originals/GBT-15834-2011.pdf#page=14)、[20](originals/GBT-15834-2011.pdf#page=20) | 间隔号可分隔标题中并列的词语；使用间隔号后，相同位置不再加“和”等并列连词。 |
| 4.15.3.1、4.15.3.5 | [15](originals/GBT-15834-2011.pdf#page=15) | 书名、篇名、文件名等使用书名号；外层用《》，内层用〈〉。 |
| A.13.1、A.13.3、A.13.4 | [20–21](originals/GBT-15834-2011.pdf#page=20) | 机构、课程、会议和活动名称按名称本身书写；书名后的“杂志”等类别词放在书名号外。括注属于作品题名时置于书名号内，否则置于书名号外。 |
| 4.17.3.3—4.17.3.5、A.14 | [16](originals/GBT-15834-2011.pdf#page=16)、[21](originals/GBT-15834-2011.pdf#page=21) | 分隔号“/”可表示选择、成对关系或类别层级，前后通常不紧接点号；正文关系容易混淆时，按实际含义写出“或”“和”等连接词。 |

## 4. 横排位置

| 条款号 | PDF 页码 | 本地使用要求 |
| --- | --- | --- |
| 5.1.1—5.1.3 | [16](originals/GBT-15834-2011.pdf#page=16) | 句号、逗号、顿号、分号、冒号及后引号、后括号、后书名号不置于行首；前引号、前括号、前书名号不置于行末。 |
