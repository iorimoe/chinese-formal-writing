# 数字用法条款摘要

## 1. 版本与来源

固定版本为 GB/T 15835—2011《出版物上数字用法》，核对日期为 2026 年 11 月 8 日。

- 标准信息：[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F5DAC3377DA99C8D78AE66735B6359C7)。
- 原文来源：[教育部网站公开的标准 PDF](https://www.moe.gov.cn/ewebeditor/uploadfile/2015/01/13/20150113091154536.pdf)。
- 本文件对应第 4 章和第 5 章；科学技术文稿的分节写法同时采用[量与符号规则](quantities-symbols.md)。

## 2. 数字形式

| 条款号 | 本地使用要求 |
| --- | --- |
| 4.1.1 | 需要计算或配有计量单位的数值采用阿拉伯数字，单位用字母符号时同样如此。 |
| 4.1.2、4.1.3 | 需要清楚辨识的编号，以及已固定使用阿拉伯数字的名称，保留阿拉伯数字形式。 |
| 4.2.1 | 农历、干支及传统历史纪年采用汉字数字。 |
| 4.2.2、5.2.1 | 相邻数字连用的概数及含“几”的概数采用汉字数字；相邻概数之间不加顿号，如“两三次”。 |
| 4.2.3 | 已固定使用汉字数字的术语和名称保留其写法，如“三元方程”。 |
| 4.3 | 两种数字形式均清楚、简洁时可按文体选用。同类内容、同级编号采用一致的形式；不同功能或层级可分别采用合适形式。 |

## 3. 数值、范围与日期

| 条款号 | 本地使用要求 |
| --- | --- |
| 5.1.1 | 一般出版物的多位整数可用千分撇或千分空；千分撇方式不分节小数部分。千分空从小数点向两侧每三位分组。科学技术领域按 GB/T 3101—1993 的 3.3.1，以空隙分组。 |
| 5.1.2 | 纯小数保留小数点前的零，小数点使用位于基线的点，如 `0.25`。 |
| 5.1.3 | 数值范围可用“～”或“—”。省略前端单位或附加符号以含义明确为条件；百分号、数量级等省略后会改变含义的内容，在两端分别保留。 |
| 5.1.3 | 范围书写示例为 `10～15 kg`、`20%～30%`、`2 万元～3 万元`、`3 × 10⁵～5 × 10⁵`。此处示例为依据条款编制的本地示例。 |
| 5.1.4 | 日期依年、月、日排列，年份写四位。完整日期可写为 `2026 年 11 月 8 日` 或 `2026-11-08`；缺年或缺日时保留“月”“日”等文字标识。 |
| 5.1.5 | 时间依时、分、秒排列，可用 12 小时制或 24 小时制；数字形式可写为 `09:30:05`。采用 12 小时制时按实际情况标明上午、下午等信息。 |
| 5.1.6、5.2.3 | 含月日的专名采用阿拉伯数字时用间隔号并加引号。采用汉字数字时，一月、十一月、十二月的月日之间使用间隔号；其他月份按固定名称书写。 |
| 5.1.7.1、5.1.7.2 | 阿拉伯数字一般采用正体半字宽；同一个数值完整置于一行。 |
| 5.2.4 | 法律文书和财务票据的金额等按要求使用大写汉字数字。 |
| 5.2.5 | 汉字数字表示计量值时，零位写“零”；逐位编号时写“〇”，如“二〇二六年”。 |
| 5.3 | 较大数值可将“万”“亿”与阿拉伯数字结合使用；一般数值的其他数位保持同一书写系统。 |

公文成文日期另按 GB/T 9704—2012 的 7.3.5.4，个位月、日前不补零。上述内容属于数字表达规则，已核实的数据和精度依据原始资料保留。
